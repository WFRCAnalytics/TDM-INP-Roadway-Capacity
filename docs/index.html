TDM Roadway Capacity

UDOT continuous count station (CCS) observed hourly volumes across the Wasatch Front network — max and average-of-max single-lane volume by facility type, mapped and filterable per station.

Observed volumes: UDOT CCS hourly-by-lane counts, each year's Sept–Nov calibration window (Tue–Thu). Model capacity assumptions and network links: a frozen snapshot of calibration run C74 from WF-TDM-Calibration (tdm_ref: calib/C74) — see this repo's README for full data provenance and how to regenerate.

Model capacity assumptions

The Wasatch Front TDM's own per-lane hourly capacity assumption, by facility type and lane count — from calibration run C74's spdcap lookup table. This is the model's input assumption, not an observed value.

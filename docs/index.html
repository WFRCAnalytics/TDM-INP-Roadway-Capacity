TDM Roadway Capacity

UDOT continuous count station (CCS) observed hourly volumes compared against the Wasatch Front travel demand model's own per-lane capacity assumptions, by facility type and lane count.

Observed volumes: UDOT CCS hourly-by-lane counts, Sept–Nov 2023 calibration window (Tue–Thu). Model capacity assumptions and network links: a frozen snapshot of calibration run C74 from WF-TDM-Calibration (tdm_ref: calib/C74) — see this repo's README for full data provenance and how to regenerate.
